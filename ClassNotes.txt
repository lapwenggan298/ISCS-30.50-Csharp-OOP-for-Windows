Access Modifiers
- private, not inherited by anyone
- public, can be inherited/accessed by anyone
- protected, can be accessed by children (?)

Input Methods:
- Console.Read()
	 > Reads the next character in the input stream (ASCII Value)

- Console.ReadLine()
	> Reads the next string of characters in the input stream

- Console.ReadKey()
	> Makes the program wait until a key is pressed.

Output Methods:
- Console.Write()
	> Writes the inputted strings without a new line character (break).

- Console.WriteLine()
	> Writes the inputted string with a new line characcter appended to the end of the string.

Misc
- C# uses "" instead of '' when writing down strings.
